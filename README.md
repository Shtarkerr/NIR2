# Image Annotator

Программа для разметки изображений. НИР за 2 курс, тема 9.
Написана на C++17 и Qt 5, собирается через CMake.

## Что умеет

- открывать изображение (через меню, перетаскиванием в окно или из командной строки);
- создавать пустой холст нужного размера и цвета (Ctrl+N);
- выбирать цвет рисования, в том числе полупрозрачный;
- выделять область прямоугольником, рамкой или с заливкой;
- отмечать отдельные точки;
- выделять область эллипсом;
- выделять область произвольным контуром: можно обвести мышью с зажатой кнопкой, а можно ставить вершины щелчками. Контур рисуется кистью, её размер меняется в поле «Кисть» или клавишами [ и ];
- сохранять разметку в JSON и экспортировать в текстовый файл.

Кроме этого у объектов есть метки, объекты можно выбирать, двигать и удалять, работает отмена действий (Ctrl+Z / Ctrl+Y). Несколько объектов выделяются протягиванием мыши по строкам в списке справа (или с Shift и Ctrl), а на холсте через Ctrl + щелчок. Выделенные объекты можно удалить или сдвинуть все сразу.

## Сборка и запуск

```bash
sudo apt install qtbase5-dev qtbase5-dev-tools cmake ninja-build g++
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build
./build/image_annotator samples/shapes.json
```

Можно открыть `CMakeLists.txt` в Qt Creator.

## Управление

| Клавиша | Действие |
|---|---|
| V | выбор и перемещение объекта, стрелки двигают на 1 px, с Shift на 10 px |
| P | точка |
| R | прямоугольник, с Shift квадрат |
| E | эллипс, с Shift круг |
| C | контур. Enter или двойной щелчок завершают, Backspace убирает последнюю вершину, Esc отменяет |
| [ и ] | уменьшить и увеличить кисть |
| F | включить или выключить заливку |
| Ctrl + щелчок | добавить объект к выделению или убрать из него |
| Del | удалить выделенные объекты |
| Ctrl+N | новый холст |
| Колесо мыши | масштаб |
| Пробел + мышь, средняя кнопка | прокрутка |

## Устройство проекта

```
src/model     классы объектов разметки и документ
src/io        сохранение в JSON и экспорт в TXT
src/tools     инструменты рисования
src/commands  команды для отмены и повтора
src/ui        главное окно, область просмотра, список объектов
tests         тесты на Qt Test
samples       пример картинки и разметки к ней
```

От базового класса `Annotation` наследуются `PointAnnotation`, `RectAnnotation`, `EllipseAnnotation` и `ContourAnnotation`. Прямоугольник и эллипс наследуются через промежуточный класс `FillableAnnotation`, потому что только их можно заливать. Общие поля (id, метку, цвет) сохраняет базовый класс, а геометрию дописывает каждый наследник.

Инструменты сделаны отдельными классами с общим предком `Tool`. Область просмотра просто передаёт текущему инструменту события мыши, а он уже решает, что рисовать.

Модель и сохранение вынесены в отдельную библиотеку `annotator_core`, которая не зависит от виджетов. Поэтому тесты запускаются без графического окна.

## Форматы файлов

Координаты везде в пикселях исходного изображения, начало в левом верхнем углу.

### JSON

Основной формат: его можно открыть обратно и продолжить разметку.

```json
{
  "format": "image-annotator",
  "version": 1,
  "image": "shapes.png",
  "width": 800,
  "height": 600,
  "labels": ["кот", "мяч"],
  "annotations": [
    {"id": 1, "type": "point", "label": "глаз", "color": "#00ff00", "x": 120, "y": 45},
    {"id": 2, "type": "rect", "label": "кот", "color": "#ff0000", "filled": false, "x": 10, "y": 20, "w": 200, "h": 150},
    {"id": 3, "type": "ellipse", "label": "мяч", "color": "#800000ff", "filled": true, "cx": 400, "cy": 300, "rx": 50, "ry": 30},
    {"id": 4, "type": "contour", "label": "дерево", "color": "#ffaa00", "closed": true, "width": 5, "vertices": [[100,100],[150,90],[160,140]]}
  ]
}
```

Путь к картинке записывается относительно файла разметки. Если разметка сделана на пустом холсте, вместо `image` пишется `"canvas": "#ffffff"`, и при открытии холст создаётся заново. У контура `width` означает размер кисти в пикселях. Цвет хранится как `#rrggbb`, а если есть прозрачность, то как `#aarrggbb`.

### TXT

Экспорт для чтения человеком или другой программой. Каждый объект записан одной строкой, у контура ещё две строки: `V` с вершинами и `P` со всеми пикселями средней линии контура по порядку (они получаются алгоритмом Брезенхэма). Толщина линии записана отдельно в `width`.

```
POINT id=1 label="глаз" color=#00ff00 x=120 y=45
RECT id=2 label="кот" color=#ff0000 filled=0 x1=10 y1=20 x2=210 y2=20 x3=210 y3=170 x4=10 y4=170
ELLIPSE id=3 label="мяч" color=#800000ff filled=1 cx=400 cy=300 rx=50 ry=30
CONTOUR id=4 label="дерево" color=#ffaa00 closed=1 width=5 vertices=3 pixels=160
  V 100 100; 150 90; 160 140
  P 100 100; 101 100; 102 100; ...
```

Вершины прямоугольника идут по часовой стрелке, начиная с левой верхней.
